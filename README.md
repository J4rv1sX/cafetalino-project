# cafetalino-project

Everything here runs inside **WSL2 (Ubuntu)**, not native Windows — open this project from a WSL terminal (or `nvim`/`claude` launched from one).

- [`backend/`](backend/README.md) — Python/uv, TensorFlow (GPU/CUDA), FastAPI
- [`frontend/`](frontend/README.md) — Vite + React + TypeScript
