# Official course documents (UNIR)

Normative documentation for the Trabajo de Investigación/Innovación of the
Maestría en Inteligencia Artificial. The `.md` files are **faithful
transcriptions** of the original documents in this directory, in plain text, so
they can be read and searched without opening a PDF viewer or Word (and so AI
tools can consult them). The transcriptions keep the original Spanish.

| Document | Contents |
|---|---|
| [guia.md](guia.md) | What the Trabajo de Innovación is, the four phases, topic request, lines of work, deliverables, presentation video and grading criteria. |
| [instrucciones.md](instrucciones.md) | How to write the document: line of discourse, structure and length (20–30 pages), template formats, writing style, APA citations and expected content of each section. |
| [programacion.md](programacion.md) | Weekly schedule: the work spread over 16 weeks, the four phases, videos, deadlines for the three activities and the weight of each deliverable in the final grade. |
| [plantilla.md](plantilla.md) | The Word template: the document's section skeleton and the guidance text describing what each section must contain, plus the formatting of table and figure titles and sources. |

Original sources: `guia.pdf`, `instrucciones.pdf`, `programacion.pdf` and
`plantilla.docx`. The **Word template is still mandatory for submission** —
`plantilla.md` is only its content in plain text; this repository's report
reproduces its structure in LaTeX under `documentation/`.
